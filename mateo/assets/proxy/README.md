# Proxies 3D originales
12 archivos `.glb` de geometría simple y materiales de color por vértice, generados para uso privado o como base de prototipo. Todos en metros aproximados, centro horizontal en 0, suelo en Y=0, Y up. No son assets de producción ni están animados. Se pueden cargar con GLTFLoader y sustituir por modelos Blender estilizados de mayor nivel. Evitar distribuirlos como "modelos fotorealistas".

Modelos: ropero, sofá, cama, mesa, silla, heladera, mesada, caja registradora, puerta, puesto de comida, banco y maceta.
